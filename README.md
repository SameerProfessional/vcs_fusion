**VCS Fusion** is a lightweight, Java-based version control system inspired by Git's core architecture.  
This project is built to help understand how modern VCS tools like Git work under the hood by re-implementing core features from scratch using Java.

---

## 🚀 Features

- Initialize a new VCS repository (`init`)
- Track file changes
- Store commit metadata
- Object storage (blobs, trees, commits)
- Lightweight and easy to understand
